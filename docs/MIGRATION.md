# Migration

Die bisherigen Kategorien werden im neuen Modell in drei Nutzungsebenen überführt:

1. **Globale Profile** unter `profiles/`
2. **Bereichsprofile** unter `.../main/`
3. **Full-Listen** unter `.../full/`

Bestehende Installationen sollten zunächst `Normal` oder `Pro` in einer Testgruppe einsetzen. `Ultimate` ist bewusst aggressiv.
