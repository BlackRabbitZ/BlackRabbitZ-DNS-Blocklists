# Quellenmodell

Statischer Build ohne automatische Fremdlisten-Synchronisation. Domainbasis: BlackRabbitZ-Snapshot mit dokumentierten Quellen wie Block List Project, AnudeepND, NextDNS Native Tracking Protection, Perflyst, URLhaus, Phishing.Database und HaGeZi-Anteilen. Struktur-/Sollkatalog: BRZ Pi-hole DNS-Listen & Kinderschutz-Handbuch (30.09.2026). HaGeZi dient zusätzlich als Referenz für kumulative Hauptstufen und getrennte Native-/Speziallisten.

## Quellenabgleich 03.10.2026

Beim manuellen Voll-Audit wurden die bestehenden BRZ-Daten zusätzlich gegen aktuelle etablierte DNS-/Pi-hole-Projekte gegengeprüft: Block List Project, StevenBlack/hosts, AdGuard DNS Filter, 1Hosts Lite, AnudeepND blacklist, Perflyst PiHoleBlocklist, NextDNS-Metadaten/Native-Tracking und HaGeZi-Spezialklassen. Universal-Listen werden nicht blind auf Spezialkategorien verteilt; übernommen werden nur kategorial belastbare Ergänzungen. Details: `docs/AUDIT_2026-10-03.md`.
