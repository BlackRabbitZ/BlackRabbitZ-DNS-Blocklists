# Quellenmodell

Die vNext-Repo ist ein **statischer Snapshot**. Sie lädt bei Builds keine Fremdlisten aus dem Internet nach.

1. Grundlage ist der aktuelle statische BlackRabbitZ-Datenbestand.
2. Dessen Listen enthalten bereits dokumentierte Anteile aus mehreren Drittprojekten, darunter HaGeZi.
3. Die HaGeZi-README und der Cheat Sheet wurden zusätzlich als Referenz für die Native-Tracker-/Stufenlogik verwendet.
4. Jeder veröffentlichte Listenheader nennt seine unmittelbare Herkunft.

Dadurch bleibt der veröffentlichte Stand reproduzierbar und ändert sich nicht unbemerkt durch einen Upstream-Refresh.
