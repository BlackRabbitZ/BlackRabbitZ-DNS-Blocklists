# Listenmodell

## Hauptlisten

Jeder größere Bereich nutzt dieselben kumulativen Stufen:

`Light ⊂ Normal ⊂ Pro ⊂ Pro++ ⊂ Ultimate`

- **Light:** möglichst sichere Werbe-/Ad-Endpunkte.
- **Normal:** Light + Tracking/Analytics.
- **Pro:** Normal + Telemetrie/Metrics/Diagnostik/Native Tracking.
- **Pro++:** Pro + aggressive Hersteller-/Cloud-/Privacy-Endpunkte.
- **Ultimate:** vollständiger bekannte Bereichsdatenbestand; kann Funktionen beeinträchtigen.

## Full-Listen

Full-Listen sind Speziallisten für genau einen Hersteller oder Dienst. Sie sind nicht automatisch die empfohlene Standardwahl.

## Keine Dateisplittung

Eine logische Liste bleibt eine Datei. Es gibt keine `part-01`, `part-02`- oder MiB-Aufteilung.
