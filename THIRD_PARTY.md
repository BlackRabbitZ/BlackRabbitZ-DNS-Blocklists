# Third-party material

This repository does not mirror complete third-party maintained DNS blocklist datasets.

Some security indicators are manually curated from external threat-intelligence and consumer-warning sources for verification and classification. The original sources remain authoritative and may change more frequently than this repository.

## Security indicator sources

- **URLhaus (abuse.ch / Spamhaus)** — verification source for malware-distribution hosts.
  - https://urlhaus.abuse.ch/
  - https://urlhaus.abuse.ch/downloads/text_online/
- **Phishing.Database** — verification source for active phishing domains. Licensed under the MIT License; preserve the upstream copyright and permission notice when redistributing substantial portions of that dataset.
  - https://github.com/Phishing-Database/Phishing.Database
- **BaFin** — public consumer warnings used to verify suspicious or fraudulent financial/trading platforms.
  - https://www.bafin.de/DE/verbraucherinnen-verbraucher/news-warnungen/news-warnungen_node.html
- **Verbraucherzentrale / Fakeshop-Finder** — public consumer warnings used to verify fake-shop domains.
  - https://www.verbraucherzentrale.de/fakeshopfinder-71560

The BlackRabbitZ lists contain only a small curated subset of indicators rather than a wholesale copy of these upstream feeds.
